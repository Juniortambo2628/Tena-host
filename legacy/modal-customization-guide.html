Modal Dialog Customization Guide

1. Basic Modal Customization

Here's how to customize your modal dialogs to match the Tena theme:

CSS Variables Approach (Recommended)

/* Add this to your CSS file */ .modal-custom { --bs-modal-bg: linear-gradient(135deg, #000000 0%, #1a1a1a 100%); --bs-modal-border-color: var(--bs-primary); --bs-modal-border-width: 2px; --bs-modal-border-radius: 20px; --bs-modal-box-shadow: 0 20px 60px rgba(0, 0, 0, 0.5); } .modal-custom .modal-content { background: var(--bs-modal-bg); border: var(--bs-modal-border-width) solid var(--bs-modal-border-color); border-radius: var(--bs-modal-border-radius); box-shadow: var(--bs-modal-box-shadow); }

HTML Usage

<div class="modal fade modal-custom" id="customModal" tabindex="-1"> <div class="modal-dialog modal-dialog-centered"> <div class="modal-content"> <div class="modal-header"> <h5 class="modal-title">Custom Modal</h5> <button type="button" class="btn-close" data-bs-dismiss="modal"></button> </div> <div class="modal-body"> Your content here </div> </div> </div> </div>

2. Advanced Modal Styling

Complete Custom Modal Styles

/* Complete custom modal styling */ .modal-custom .modal-header { border-bottom: 1px solid rgba(255, 211, 0, 0.3); background: rgba(255, 211, 0, 0.1); border-radius: 18px 18px 0 0; } .modal-custom .modal-title { color: var(--bs-primary); font-weight: bold; font-size: 1.25rem; } .modal-custom .btn-close { filter: invert(1); opacity: 0.8; } .modal-custom .btn-close:hover { opacity: 1; } .modal-custom .modal-body { color: white; padding: 2rem; } .modal-custom .form-control { background: rgba(255, 255, 255, 0.1); border: 1px solid rgba(255, 211, 0, 0.3); color: white; border-radius: 10px; } .modal-custom .form-control:focus { background: rgba(255, 255, 255, 0.15); border-color: var(--bs-primary); box-shadow: 0 0 0 0.2rem rgba(255, 211, 0, 0.25); color: white; } .modal-custom .form-control::placeholder { color: rgba(255, 255, 255, 0.6); } .modal-custom .btn-primary { background: var(--bs-primary); color: #000; border: none; font-weight: 600; padding: 0.75rem 2rem; border-radius: 25px; transition: all 0.3s ease; } .modal-custom .btn-primary:hover { background: #e6c200; transform: translateY(-2px); box-shadow: 0 5px 15px rgba(255, 211, 0, 0.3); }

3. Modal Animations

Custom Animation Classes

/* Modal animations */ .modal-animated { animation: modalSlideIn 0.3s ease-out; } @keyframes modalSlideIn { from { opacity: 0; transform: scale(0.8) translateY(-50px); } to { opacity: 1; transform: scale(1) translateY(0); } } .modal-backdrop-custom { background: rgba(0, 0, 0, 0.8); backdrop-filter: blur(5px); transition: all 0.3s ease; }

JavaScript for Enhanced Animations

// Enhanced modal animations document.addEventListener('DOMContentLoaded', function() { const modals = document.querySelectorAll('.modal'); modals.forEach(modal => { modal.addEventListener('show.bs.modal', function() { // Add animation class when modal opens this.classList.add('modal-animated'); // Create custom backdrop const backdrop = document.createElement('div'); backdrop.className = 'modal-backdrop-custom'; backdrop.id = 'custom-backdrop'; document.body.appendChild(backdrop); }); modal.addEventListener('hidden.bs.modal', function() { // Remove animation class this.classList.remove('modal-animated'); // Remove custom backdrop const backdrop = document.getElementById('custom-backdrop'); if (backdrop) { backdrop.remove(); } }); }); });
